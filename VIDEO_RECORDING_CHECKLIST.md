# Demo recording checklist

No new footage was recorded during release preparation.

## Full uncut evidence recording

- Show the pinned source/version and clock.
- Show the Executor/collector health and evidence-window boundary before the run.
- Record the entire run without cuts: investigation → injected `$9` proposal → refusal → legitimate proposal → authorized attempt → lost response / `OUTCOME_UNKNOWN` → locked replacement refusal → restart → reconcile original order.
- Preserve raw prompts, model responses, Gate decisions, and independent window-scoped Executor logs.
- Hide credentials, buyer data, approval URLs, password managers, and unrelated applications.

## Edited demonstration (about 2:45)

- Use the same event order as the uncut recording.
- Label every cut, time compression, or speed-up on screen.
- Keep the version label visible. If v0.5 live qualification is unavailable, use only the retained v0.3 restart footage and narrow the narration to v0.3 recovery.
- Do not imply that fixture observations are PayPal-provider evidence or that QF-01 passed.

## Publication gate

Before upload, re-run the secret/privacy review on the rendered video and description. Confirm that no credential, buyer, merchant, approval, or local-path information is visible.
